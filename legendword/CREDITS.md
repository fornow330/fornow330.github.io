# 致谢与第三方说明

《传奇文字》是纯原生实现：**无前端框架、无打包工具、无运行时第三方库**。完整本体就一个 `game.html`，所有样式与逻辑都内联在文件里。

## 分发链路中的第三方服务

| 服务 | 用途 | 性质 |
|---|---|---|
| GitHub Pages / raw.githubusercontent.com | 源码托管、在线页 | GitHub 官方 |
| fastly.jsdelivr.net | 资源加速（首选） | jsDelivr 官方 CDN |
| ghproxy.net | 资源加速（备用） | 社区第三方镜像，仅转发 raw 内容 |
| gh-proxy.com | 资源加速（备用二） | 社区第三方镜像，仅转发 raw 内容 |

镜像只做文本转递，不参与构建。

## 素材

- **图形**：全部为内联 SVG 或 CSS 绘制，未使用外部图片、图标库或字体文件
- **字体**：只使用系统字体栈（`-apple-system` 等），不外链 Google Fonts
- **音效**：无外部音频资源
- **文案与数值**：本项目原创设计，未引用他人游戏数据

## 参考概念（仅名称沿用，实现均自写）

“传奇”类玩法中的等级 / 转生 / 雷劫 / 灵器 / 词条等属于该类游戏的通用概念，本项目未使用任何他人的代码、美术或数据表。
